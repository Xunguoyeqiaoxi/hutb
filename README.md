## 🔎 如何使用

1. 在上方索引中选择课程，进入对应文件夹。
2. 点击文件可在线预览，或下载到本地使用。
3. 资料内容与教学安排可能存在差异，请以任课教师发布的信息为准。

如需完整下载仓库，建议先安装 [Git LFS](https://git-lfs.com/)：

```bash
git lfs install
git clone https://github.com/Xunguoyeqiaoxi/hutb.git
```

## 📮 投稿与补充资料

欢迎提交试卷、复习资料、参考答案和学习笔记。

### 通过 Pull Request 投稿

1. Fork 本仓库。
2. 将资料放进对应课程文件夹；没有对应课程时可新建课程文件夹。
3. 文件名建议采用：`课程名称-学年学期-资料类型`。
4. 提交修改并发起 Pull Request。

### 通过 Issue 投稿

不熟悉 Git 也可以在 [Issues](https://github.com/Xunguoyeqiaoxi/hutb/issues) 中新建议题，并写明：

- 课程名称与学年学期
- 资料类型
- 资料来源或必要说明
- 附件或可访问的资料链接

## ✅ 投稿前请确认

- 已删除姓名、学号、联系方式等个人信息。
- 不包含账号、密码或其他敏感内容。
- 内容清晰、完整，并与课程学习相关。
- 资料允许公开分享；如有侵权，请提交 Issue 联系删除。

## 🤝 参与维护

你可以帮助补充资料、整理文件、修正命名或完善课程分类。欢迎提交 Issue 和 Pull Request。

仓库资料仅供学习、复习和学术交流使用，不保证内容完全准确或适用于全部教学班级。请遵守课程资料的版权与使用要求。

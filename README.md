# 湖南工商大学期末试卷资料库

本仓库整理了湖南工商大学部分课程的期末试卷、复习资料、参考答案及学习笔记，方便同学们复习与交流。

- 统计学

- 经济学通论
- 财务管理

- 管理信息系统

- 中国传统文化概论
- 中国文化英语
- 职场英语

## 📖 使用方法

1. 在仓库中找到对应的课程文件夹。
2. 点击文件即可在线预览或下载到本地。
3. 部分资料包含试卷、参考答案和复习笔记，请结合实际教学安排使用。

如需完整克隆本仓库，建议先安装 Git LFS：

```bash
git lfs install
git clone https://github.com/ychq1314/hutb.git
```

## 📮 投稿方式

欢迎同学们投稿试卷、复习资料、参考答案和学习笔记。

### 方式一：提交 Pull Request（推荐）

1. Fork 本仓库。
2. 将资料放入对应的课程文件夹；没有对应课程时，可以新建文件夹。
3. 文件名建议使用“课程名称 + 学年 + 学期 + 试卷类型”。
4. 提交修改并发起 Pull Request。

### 方式二：通过 Issue 投稿

如果不会使用 Git，可以前往仓库的 [Issues](https://github.com/ychq1314/hutb/issues) 页面新建议题，并填写：

- 课程名称
- 学年和学期
- 资料类型
- 资料来源或必要说明

然后上传附件或提供资料链接，仓库维护者会整理后收录。

### 投稿要求

- 请删除姓名、学号、联系方式等个人隐私信息。
- 请勿上传账号、密码或其他敏感内容。
- 投稿内容应当清晰、完整，并与课程学习相关。
- 请确认资料允许公开分享；如涉及侵权，将及时删除。
